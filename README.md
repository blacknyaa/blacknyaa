## プロフィール

日本を拠点にするフリーランスの **生成AI × Web開発エンジニア** です。設計、実装、運用までをひとりで通し、本番で動かし続けられる形まで仕上げます。

8年以上にわたり、**Web・サイト・アプリを170件以上**、**システムを80件以上** 手がけてきました。データベースの設計から画面までを一気通貫で組み、既存のプロダクトへ AI を接続することも仕事の中心です。

- **一気通貫の設計** — スキーマから UI まで、拡張と保守を前提に組み立てる
- **AI の組み込み** — RAG や自動化を、いま動いている Web とバックエンドへ接続する
- **本番の基盤** — コンテナと CI/CD を前提に、運用まで見据えて構成する

プロフィールに掲げている基準は、**RAG 精度 98%**、**完了率 100%**、**設計から運用までひとりで完結** です。
